# ⚽ ゴールハイライト（iPhone向け・無料版）

試合動画のスコア表示をOCRで解析し、スコアが変化した時点をゴールとして、前15秒〜後10秒をブラウザ内で切り出すWebアプリです。

## 想定環境
- iPhone / iPad の Safari
- PCのChrome / Edgeでもテスト可能
- GitHub PagesなどのHTTPS静的ホスティング

## 完全無料の構成
- Tesseract.js：ブラウザOCR
- ffmpeg.wasm：ブラウザ内動画切り出し
- サーバーへ試合動画をアップロードしない設計
- 有料API・Firebase Functionsは使用しない

## 使い方
1. 試合動画を選択
2. 「スコア解析開始」
3. ゴールが検出されたら「切り出しエンジンを準備」
4. 「ゴール動画を作成」
5. 個別ゴール動画、または ALL_GOALS.mp4 を保存

## 注意
この版はまず1〜3分程度の動画で実機検証するための試作版です。30分動画ではiPhoneのメモリ・処理速度による制限があるため、実機テスト後に解析方式を最適化します。

## スコア表示位置
今回の基準動画（910×512）では、左上のスコア領域を相対座標で切り出しています。別の撮影設定でスコア表示位置が変わる場合はROI調整が必要です。

## Vite
FFmpeg coreはVite向けにESM版を使用しています。
